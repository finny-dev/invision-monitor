# invision-monitor

Small Tool that allows you to monitor new / existing topics on an invision community

## Setup
- Install the folder
- Extract it to your chosen location
- Open a Command Prompt Window in that folder (Click on the path i.e C:\User\invision-monitor and type "cmd" then click enter)
- Type node index.js

## Requirements
- Install [Node.js](https://nodejs.org/en)
